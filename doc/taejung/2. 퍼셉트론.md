### 학습 - 퍼셉트론,

## 0. 서론

이번에는 퍼셉트론에 대해서 알아보겠습니다.

퍼셉트론은 1957년에 프랭크 로젠블랫이 고안한 알고리즘으로, 근본적으로 인간의 뇌가 학습하는 방식을 모방해서 데이터를 자동으로 분류하는 기계를 만들기 위해 고안된 알고리즘입니다.

당시 가장 대표적인 목적은 선형 분리 가능한 분류문제를 해결하는 것이었죠. 즉 데이터에 선을 하나 그어서 두 그룹으로 나눌수 있는가? 를 해결하는 것이었습니다.

퍼셉트론 이전의 컴퓨터는 사람이 일일이 규칙을 정해줘야만 작동했으나 퍼셉트론은 스스로 규칙을 찾는 정량적 매커니즘을 제시했습니다.

- 가중치 도입: 입력데이터의 중요도를 스스로 조절합니다.
- 오차 기반 업데이트: 정답과 예측값이 다르다면, 그 오차만큼 가중치를 수정(학습)합니다. 
	
즉 데이터만 던져주면 컴퓨터가 알아서 분류기준(선형 경게면)을 찾아가는 머신러닝의 시초가 된 알고리즘이죠.

그러면 이제 퍼셉트론의 가장 기초적인 정의부터 시작해서, '여러 개의 입력이 있을 때 어떻게 완벽한 가중치를 찾아내는지'에 대한 수학적 증명인 퍼셉트론 수렴 정리(Perceptron Convergence Theorem)까지 깊이 있게 파헤쳐 보겠습니다.

## 1. 퍼셉트론의 구조와 작동 원리

퍼셉트론은 생물의 신경세포(뉴런)를 모방했습니다. 가지돌기로부터 여러 신호를 받아 시냅스에서 증폭/감쇄한 뒤, 세포체에서 합산하여 축삭돌기를 통해 다음 뉴런으로 신호를 보낼지 말지(0 또는 1) 결정하는 구조입니다.

### 수학적 모델링

입력값이 $n$개인 퍼셉트론의 내부 연산은 크게 두 단계로 나뉩니다.

1. **선형 합산 (Linear Combination):** 입력값($x$)과 가중치($w$)를 각각 곱한 뒤, 전체를 더하고 편향($b$, Bias)을 더합니다.
    
    $$z = w_1x_1 + w_2x_2 + \dots + w_nx_n + b = \sum_{i=1}^{n} w_ix_i + b$$
    
    - 수식을 깔끔하게 만들기 위해 편향 $b$를 $w_0$로, 항상 1의 값을 가지는 가상 입력 $x_0 = 1$을 도입하여 벡터의 내적(Dot Product)으로 표현합니다.
        
        $$z = \mathbf{w}^T\mathbf{x}$$
        
2. **활성화 함수 (Activation Function):** 합산된 값 $z$가 0보다 크면 1, 0 이하면 -1(또는 0)을 출력합니다. 퍼셉트론은 계단 함수(Step Function)를 사용합니다.
    
    $$y = f(z) = \begin{cases} 1 & \text{if } \mathbf{w}^T\mathbf{x} > 0 \\ -1 & \text{if } \mathbf{w}^T\mathbf{x} \le 0 \end{cases}$$
    

이 $\mathbf{w}^T\mathbf{x} = 0$이 되는 지점들이 모여 데이터 공간을 두 개로 가르는 **결정 경계(Decision Boundary)**, 즉 초평면(Hyperplane)을 형성합니다.

## 2. 퍼셉트론 학습 규칙 (Learning Rule)

퍼셉트론은 예측이 틀렸을 때만 가중치를 업데이트하는 **오류 역전파의 최첨단 조상 격인 규칙**을 따릅니다.

학습 데이터 쌍을 $(\mathbf{x}_k, y_k)$라고 하겠습니다. 여기서 $y_k \in {+1, -1}$은 실제 정답(레이블)입니다.

- **예측이 맞았을 때 ($\hat{y}_k = y_k$):** 가중치를 건드리지 않습니다.
    
- **예측이 틀렸을 때 ($\hat{y}_k \neq y_k$):** 가중치 벡터를 다음과 같이 업데이트합니다. (학습률 $\alpha = 1$로 가정)
    
    $$\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} + y_k\mathbf{x}_k$$
    

### 왜 이 식대로 하면 학습이 될까?

틀렸을 때의 상황을 기하학적으로 보면 이해가 쉽습니다.

- **정답은 $+1$인데 예측을 $-1$로 한 경우:** 현재 $\mathbf{w}^T\mathbf{x}_k \le 0$인 상태입니다. 0보다 커지게 만들어야 하므로, $\mathbf{w}$에 $\mathbf{x}_k$를 더해줍니다 ($\mathbf{w} + \mathbf{x}_k$). 그러면 다음 계산 때 내적값 $\mathbf{w}^T\mathbf{x}_k$가 커지면서 정답인 $+1$ 쪽으로 경계면이 회전합니다.
    
- **정답은 $-1$인데 예측을 $+1$로 한 경우:** 현재 $\mathbf{w}^T\mathbf{x}_k > 0$인 상태입니다. 0보다 작아지게 만들어야 하므로, $\mathbf{w}$에서 $\mathbf{x}_k$를 빼줍니다 ($\mathbf{w} - \mathbf{x}_k$).
    

이 단순한 덧셈·뺄셈을 반복하는 것이 퍼셉트론 학습의 전부입니다.

## 3. 퍼셉트론 수렴 정리 (Perceptron Convergence Theorem)

이제 핵심 질문인 "입력이 여러 개일 때 이 짓을 반복하면 진짜로 '유한한 횟수' 안에 완벽한 정답 가중치를 찾을 수 있는가?"에 대한 증명입니다. 이 증명은 1962년 블록(Block)과 노비코프(Novikoff) 등에 의해 완성되었습니다.

### 전제 조건

1. **선형 분리 가능성 (Linearly Separable):** 두 클래스를 완벽하게 가를 수 있는 최적의 가중치 벡터 $\mathbf{w}^*$가 반드시 존재한다고 가정합니다. (편의상 $\|\mathbf{w}^*\| = 1$로 정규화)
    
2. 정답 가중치 $\mathbf{w}^*$는 모든 데이터에 대해 올바르게 분류하므로, 다음을 만족하는 어떤 양수 마진(Margin) $\gamma$가 존재합니다.
    
    $$y_k(\mathbf{w}^{*T}\mathbf{x}_k) \ge \gamma > 0 \quad (\text{모든 } k\text{에 대해})$$
    
3. 모든 입력 데이터 벡터의 크기(길이)는 어떤 상수 $R$보다 작습니다.
    
    $$\|\mathbf{x}_k\| \le R \quad (\text{모든 } k\text{에 대해})$$
    

### 증명 과정

초기 가중치를 $\mathbf{w}^{(0)} = \mathbf{0}$이라고 두고, 알고리즘이 가중치를 업데이트할 때마다 **현재 가중치 $\mathbf{w}^{(t)}$가 정답 가중치 $\mathbf{w}^*$와 얼마나 가까워지는지**를 상한선(Upper bound)과 하한선(Lower bound)을 이용해 옥죄어 들어갑니다.

#### Step 1. 두 벡터의 내적 하한선 구하기 (얼마나 일치해가는가?)

가중치가 $t$번째 업데이트될 때 틀린 데이터 $\mathbf{x}_k$를 만났다고 가정합시다. 즉, $y_k(\mathbf{w}^{(t)T}\mathbf{x}_k) \le 0$인 상태입니다. 업데이트 식 양변에 정답 가중치 $\mathbf{w}^*$를 내적해 줍니다.

$$\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} + y_k\mathbf{x}_k$$

$$\mathbf{w}^{*T}\mathbf{w}^{(t+1)} = \mathbf{w}^{*T}\mathbf{w}^{(t)} + y_k(\mathbf{w}^{*T}\mathbf{x}_k)$$

전제 조건 (2)에 의해 $y_k(\mathbf{w}^{*T}\mathbf{x}_k) \ge \gamma$ 이므로,

$$\mathbf{w}^{*T}\mathbf{w}^{(t+1)} \ge \mathbf{w}^{*T}\mathbf{w}^{(t)} + \gamma$$

이 짓을 첫 번째($t=0$)부터 업데이트 횟수 $M$번까지 누적해서 전개하면 다음과 같은 **하한선**이 나옵니다.

$$\mathbf{w}^{*T}\mathbf{w}^{(M)} \ge M\gamma \quad \cdots \text{(식 1)}$$

#### Step 2. 현재 가중치 벡터 크기의 상한선 구하기 (너무 발산하진 않는가?)

이번에는 현재 가중치 벡터 $\mathbf{w}^{(t+1)}$의 크기(L2 노름의 제곱)를 계산해 봅니다.

$$\|\mathbf{w}^{(t+1)}\|^2 = \|\mathbf{w}^{(t)} + y_k\mathbf{x}_k\|^2 = \|\mathbf{w}^{(t)}\|^2 + 2y_k(\mathbf{w}^{(t)T}\mathbf{x}_k) + y_k^2\|\mathbf{x}_k\|^2$$

여기서 두 가지 사실을 대입합니다.

1. 업데이트를 했다는 것 자체가 틀렸다는 뜻이므로 $y_k(\mathbf{w}^{(t)T}\mathbf{x}_k) \le 0$입니다. 즉, 중간 항은 0 이하이므로 날려버릴 수 있습니다.
    
2. $y_k^2 = 1$이고, 전제 조건 (3)에 의해 $\|\mathbf{x}_k\|^2 \le R^2$입니다.
    

이를 정리하면,

$$\|\mathbf{w}^{(t+1)}\|^2 \le \|\mathbf{w}^{(t)}\|^2 + R^2$$

이것 역시 $M$번 업데이트할 때까지 누적해서 전개하면 다음과 같은 **상한선**이 나옵니다.

$$\|\mathbf{w}^{(M)}\|^2 \le MR^2 \quad \implies \quad \|\mathbf{w}^{(M)}\| \le \sqrt{M}R \quad \cdots \text{(식 2)}$$

#### Step 3. 하한선과 상한선 합치기

코시-슈바르츠 부등식(Cauchy-Schwarz inequality)에 의해, 두 벡터의 내적은 각 벡터의 크기의 곱보다 작거나 같습니다.

$$\mathbf{w}^{*T}\mathbf{w}^{(M)} \le \|\mathbf{w}^*\| \|\mathbf{w}^{(M)}\| = 1 \times \|\mathbf{w}^{(M)}\| = \|\mathbf{w}^{(M)}\|$$

이제 여기에 (식 1)의 하한선과 (식 2)의 상한선을 대입합니다.

$$M\gamma \le \mathbf{w}^{*T}\mathbf{w}^{(M)} \le \|\mathbf{w}^{(M)}\| \le \sqrt{M}R$$

$$M\gamma \le \sqrt{M}R$$

양변을 제곱합니다.

$$M^2\gamma^2 \le M R^2$$

양변을 $M\gamma^2$으로 나누면 최종적으로 업데이트 횟수 $M$에 대한 한계치가 도출됩니다.

$$M \le \frac{R^2}{\gamma^2}$$

## 4. 결론: 수렴 원리의 의미

위의 수식이 말해주는 결론은 매우 명확하고 강력합니다.

> 데이터가 선형 분리 가능하다면, 퍼셉트론이 학습하면서 발생하는 **가중치 업데이트의 총 횟수($M$)는 데이터의 최대 크기($R$)와 마진($\gamma$)으로 결정되는 고정된 상수 $\frac{R^2}{\gamma^2}$를 절대 넘을 수 없다.**

즉, 입력 특성(Feature)의 개수 $n$이 10개든, 1000개든 상관없이 데이터가 직선(초평면)으로 쪼개질 수 있는 구조이기만 하면, 퍼셉트론은 **무조건 유한한 단계 안에 학습을 완료하고 100% 완벽한 경계선을 찾아낸다**는 점이 수학적으로 완벽하게 보장됩니다.

이것이 퍼셉트론이 여러 개의 입력을 받아도 길을 잃지 않고 제대로 학습할 수 있는 본질적인 원리입니다.
