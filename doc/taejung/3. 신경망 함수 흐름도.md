# 신경망 함수 흐름도

## 0. 서론

이번 문서는 MNIST 신경망 코드가 어떤 순서로 실행되는지 정리한 흐름도입니다.

핵심은 다음 네 단계입니다.

```text
forward -> loss -> backward -> update
```

- `forward`: 입력 이미지로 예측값을 만듭니다.
- `loss`: 예측값과 정답을 비교해서 손실을 계산합니다.
- `backward`: 손실을 줄이기 위해 각 층이 gradient를 계산합니다.
- `update`: optimizer가 gradient를 이용해 실제 파라미터를 수정합니다.

## 1. 전체 학습 흐름

학습의 가장 바깥쪽 흐름은 `train()` 함수가 담당합니다.

```text
train()
├─ epoch 반복
│  └─ batch 반복
│     ├─ model.forward(x_batch)
│     │  └─ 예측 확률 y_pred 계산
│     │
│     ├─ cross_entropy_loss(y_pred, y_batch)
│     │  └─ 예측과 정답의 차이를 loss로 계산
│     │
│     ├─ dout 생성
│     │  └─ Softmax + CrossEntropy를 합친 gradient 생성
│     │
│     ├─ model.backward(dout)
│     │  └─ 각 층을 역순으로 통과하면서 gradient 계산
│     │
│     └─ optimizer.update(model.params, model.grads)
│        └─ W, b, gamma, beta 같은 파라미터 갱신
│
└─ loss_history 반환
```

즉 `train()`은 직접 수학 연산을 모두 하는 함수라기보다, 학습에 필요한 함수들을 올바른 순서로 호출하는 지휘자 역할입니다.

## 2. Forward 흐름

`forward`는 입력 데이터가 신경망을 앞쪽에서 뒤쪽으로 통과하는 과정입니다.

MNIST 이미지는 28x28 픽셀이므로 펼치면 784차원 벡터가 됩니다.

```text
model.forward(x_batch)
├─ Affine.forward()
│  └─ x @ W + b
│
├─ BatchNorm.forward()
│  └─ 배치 평균과 분산으로 정규화
│
├─ ReLU.forward()
│  └─ 0 이하 값은 0, 양수는 그대로 통과
│
├─ Dropout.forward()
│  └─ 학습 중 일부 뉴런을 무작위로 끔
│
├─ Affine.forward()
│  └─ 다음 은닉층으로 선형 변환
│
├─ BatchNorm.forward()
│  └─ 다시 정규화
│
├─ ReLU.forward()
│  └─ 비선형성 추가
│
├─ Dropout.forward()
│  └─ 과적합 완화
│
├─ Affine.forward()
│  └─ 10개 클래스 로짓 생성
│
└─ Softmax.forward()
   └─ 로짓을 확률로 변환
```

forward의 결과는 다음과 같은 확률 행렬입니다.

```text
y_pred shape = (batch_size, 10)
```

각 행은 하나의 이미지에 대한 예측이고, 10개 값은 숫자 0부터 9까지의 확률입니다.

## 3. Loss 흐름

`cross_entropy_loss()`는 모델의 예측 확률과 실제 정답을 비교합니다.

```text
cross_entropy_loss(y_pred, y_batch)
├─ y_pred에서 정답 클래스의 확률만 선택
├─ -log(정답 확률) 계산
├─ batch 전체 평균 계산
└─ loss 반환
```

예를 들어 정답이 5인데 모델이 숫자 5의 확률을 높게 예측했다면 loss는 작습니다.  
반대로 정답이 5인데 숫자 2의 확률을 높게 예측했다면 loss는 커집니다.

## 4. Backward 흐름

`backward`는 loss에서 시작해서 forward의 반대 방향으로 gradient를 흘려보내는 과정입니다.

```text
model.backward(dout)
├─ Softmax.backward()
│  └─ 이미 만들어진 gradient를 그대로 통과
│
├─ Affine.backward()
│  ├─ dW 계산
│  ├─ db 계산
│  └─ dx 계산
│
├─ Dropout.backward()
│  └─ forward 때 꺼진 뉴런의 gradient 차단
│
├─ ReLU.backward()
│  └─ forward 때 0 이하였던 위치의 gradient 차단
│
├─ BatchNorm.backward()
│  ├─ dgamma 계산
│  ├─ dbeta 계산
│  └─ dx 계산
│
├─ Affine.backward()
│  ├─ dW 계산
│  ├─ db 계산
│  └─ dx 계산
│
├─ Dropout.backward()
│  └─ forward 때 꺼진 뉴런의 gradient 차단
│
├─ ReLU.backward()
│  └─ forward 때 0 이하였던 위치의 gradient 차단
│
├─ BatchNorm.backward()
│  ├─ dgamma 계산
│  ├─ dbeta 계산
│  └─ dx 계산
│
└─ Affine.backward()
   ├─ dW 계산
   ├─ db 계산
   └─ dx 계산
```

forward가 다음 순서였다면:

```text
Affine -> BatchNorm -> ReLU -> Dropout -> Affine -> BatchNorm -> ReLU -> Dropout -> Affine -> Softmax
```

backward는 정확히 반대 순서로 진행됩니다.

```text
Softmax -> Affine -> Dropout -> ReLU -> BatchNorm -> Affine -> Dropout -> ReLU -> BatchNorm -> Affine
```

## 5. 각 Backward 함수의 책임

### Softmax.backward

이 과제 구조에서는 `Softmax.backward()`가 받은 `dout`을 그대로 반환합니다.

```text
Softmax.backward(dout)
└─ return dout
```

이유는 `train()`에서 Softmax와 Cross Entropy를 합친 미분값을 이미 만들기 때문입니다.

```text
dout = y_pred - 정답 one-hot
```

따라서 Softmax가 다시 복잡한 미분을 할 필요가 없습니다.

### Affine.backward

Affine 계층은 `W`, `b`라는 학습 파라미터를 가지고 있습니다.  
그래서 `backward`에서 이 파라미터들의 gradient를 계산해야 합니다.

```text
Affine.backward(dout)
├─ self.dW = self.x.T @ dout
├─ self.db = sum(dout, axis=0)
├─ dx = dout @ W.T
└─ return dx
```

- `dW`: 가중치 `W`를 어떻게 바꿔야 하는지
- `db`: 편향 `b`를 어떻게 바꿔야 하는지
- `dx`: 앞 계층으로 넘길 gradient

### Dropout.backward

Dropout은 forward 때 일부 뉴런을 껐습니다.  
그러면 backward 때도 그 위치로 gradient가 흐르면 안 됩니다.

```text
Dropout.backward(dout)
├─ dx = dout * mask
└─ return dx
```

`mask`는 forward 때 어떤 뉴런이 살아 있었는지 기록한 boolean 배열입니다.

### ReLU.backward

ReLU는 forward 때 0 이하 값을 0으로 막았습니다.  
따라서 그 위치는 출력에 영향을 주지 않았으므로 backward 때 gradient도 막아야 합니다.

```text
ReLU.backward(dout)
├─ dx = dout * mask
└─ return dx
```

여기서 `mask`는 `x > 0`인 위치를 저장한 boolean 배열입니다.

```text
True  = gradient 통과
False = gradient 차단
```

### BatchNorm.backward

BatchNorm은 정규화 과정과 `gamma`, `beta` 파라미터를 가지고 있습니다.  
따라서 backward에서 세 가지를 계산해야 합니다.

```text
BatchNorm.backward(dout)
├─ dgamma 계산
├─ dbeta 계산
├─ dx 계산
└─ return dx
```

- `dgamma`: scale 파라미터 `gamma`의 gradient
- `dbeta`: shift 파라미터 `beta`의 gradient
- `dx`: 정규화 이전 입력으로 되돌려 보낼 gradient

## 6. Update 흐름

`backward`가 끝나면 각 파라미터의 gradient가 준비됩니다.

그 다음 optimizer가 실제 파라미터 값을 수정합니다.

```text
optimizer.update(model.params, model.grads)
├─ params["W1"] 갱신
├─ params["b1"] 갱신
├─ params["gamma1"] 갱신
├─ params["beta1"] 갱신
├─ params["W2"] 갱신
├─ params["b2"] 갱신
└─ ...
```

SGD라면 기본 형태는 다음과 같습니다.

```text
param = param - learning_rate * gradient
```

Adam은 여기에 gradient의 이동평균과 제곱 이동평균을 추가로 사용합니다.

## 7. 한 줄 요약

전체 흐름을 가장 짧게 쓰면 다음과 같습니다.

```text
입력 이미지
-> forward로 예측
-> loss로 틀린 정도 계산
-> backward로 각 파라미터의 수정 방향 계산
-> optimizer가 실제 파라미터 업데이트
-> 다음 batch에서 반복
```

forward는 예측값을 만드는 길이고, backward는 그 예측을 고치기 위한 정보를 되돌려 보내는 길입니다.
