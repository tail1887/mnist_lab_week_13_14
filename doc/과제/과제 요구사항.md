# 과제: 신경망을 이용한 손글씨 숫자 인식

## 1. 개요

본 과제는 PyTorch, TensorFlow 같은 딥러닝 프레임워크 없이 **NumPy만으로 신경망의 핵심 구성 요소를 직접 구현**하는 것을 목표로 합니다.

- 최종 목표: MNIST 필기체 숫자 분류기 구현, 테스트 정확도 **97% 이상** 권장
- 최소 목표: 테스트 정확도 **95% 이상**
- 참고 도서: 『밑바닥부터 시작하는 딥러닝』 1~6장

이번 과제에서 만드는 것은 손글씨 이미지를 보고 0~9 중 하나를 고르는 프로그램입니다. 이미지는 28x28 픽셀이고, 컴퓨터는 이 이미지를 784개의 숫자로 봅니다. 신경망은 이 숫자들을 여러 층에 통과시키며 각 숫자일 가능성을 계산합니다.

이 과제는 정확도만 맞히는 과제가 아닙니다. **Forward, loss, backward, optimizer update가 어떤 순서로 연결되는지** 팀원이 모두 설명할 수 있어야 합니다.

처음부터 정확도 97%를 목표로 하기보다, 각 레이어의 테스트를 하나씩 통과시키고 loss가 줄어드는지 확인하는 것이 먼저입니다.

## 8. 학습 루프 규칙

각 미니배치마다 반드시 다음 순서를 지킵니다.

1. Forward: `model.forward(x_batch, train=True)`
2. Loss: `cross_entropy_loss(y_pred, y_batch)`
3. Backward: softmax와 cross entropy의 gradient 계산 후 `model.backward(dout)`
4. Update: `optimizer.update(model.params, model.grads)`

주의:

- 테스트 단계에서는 `train=False`로 Dropout과 BatchNorm 동작을 바꿔야 합니다.
- Forward에서 저장한 중간 값은 Backward에서 재사용합니다.
- 파라미터와 gradient의 shape가 항상 같아야 합니다.
- 수치 안정성을 위해 Softmax와 Cross Entropy에는 작은 epsilon 또는 max-shift를 적용합니다.

초심자가 자주 막히는 지점:

| 지점 | 확인 방법 |
| --- | --- |
| `ReLU.backward` | `x <= 0`인 위치의 gradient가 0인지 확인 |
| `Affine.backward` | `dW.shape == W.shape`, `db.shape == b.shape`인지 확인 |
| Softmax + Cross Entropy | `dout = y_pred.copy(); dout[range(batch), y] -= 1; dout /= batch` 순서 확인 |
| BatchNorm | train일 때 batch mean/var, test일 때 running mean/var를 쓰는지 확인 |
| Dropout | train일 때만 mask를 새로 만들고, test일 때는 고정 비율로 scale하는지 확인 |

## 9. 신경망 구조 예시

기본 구조:

```text
입력 784
-> Affine(512)
-> BatchNorm
-> ReLU
-> Dropout
-> Affine(256)
-> BatchNorm
-> ReLU
-> Dropout
-> Affine(10)
-> Softmax
```

권장 설정:

| 항목 | 권장 값 |
| --- | --- |
| hidden layers | 1개 이상 |
| batch size | 128 |
| epochs | 15~20 |
| optimizer | Adam |
| learning rate | 0.001부터 실험 |
| dropout ratio | 0.2 또는 0.3 |
| BatchNorm momentum | 0.9 |
| weight initialization | He 또는 Xavier |

목표 정확도에 도달하지 못한 경우 다음 순서로 점검합니다.

1. 학습 손실이 감소하는지 확인합니다.
2. `train=True`와 `train=False` 동작이 구분되는지 확인합니다.
3. BatchNorm의 running mean, running variance가 갱신되는지 확인합니다.
4. Dropout이 학습 때만 적용되는지 확인합니다.
5. learning rate를 0.001, 0.0005, 0.0001로 바꿔 실험합니다.

## 10. 실험과 검증

필수로 기록할 항목:

| 항목 | 설명 |
| --- | --- |
| 모델 구조 | 은닉층 수, 각 층의 차원, 활성화 함수 |
| 학습 설정 | optimizer, learning rate, epochs, batch size |
| 정규화·규제 | BatchNorm 사용 여부, Dropout 비율 |
| 초기화 | He, Xavier, 직접 설정 중 무엇을 사용했는지 |
| 결과 | train loss, test accuracy, 파라미터 수 |
| 시간 | Colab 또는 로컬에서 걸린 학습 시간 |

권장 시각화:

- epoch별 loss curve
- learning rate 변경에 따른 정확도 비교
- Dropout 적용 전후 정확도 비교

사용 함수:

- `evaluate(model, x, y)`: 정확도(%)와 총 파라미터 수 반환 (구현됨). 목표 정확도 95% 이상, 권장 97% 이상.
- `plot_loss_history(loss_history)`: 손실 커브 그래프 (구현됨).

Colab CPU 기준으로도 진행 가능하지만, epoch 수와 hidden layer 크기에 따라 학습 시간이 달라질 수 있습니다. 먼저 작은 모델로 테스트를 통과시킨 뒤 목표 정확도를 위해 모델을 키우는 흐름을 권장합니다.
